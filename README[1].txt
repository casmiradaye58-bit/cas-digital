CAS DIGITAL — site + administration
====================================

index.html : site public.
admin.html : interface d'administration du catalogue.
assets/logo.jpg : logo fourni.
catalogue.json : sauvegarde/export du catalogue.

Administration :
- ajouter un ordinateur
- modifier ses caractéristiques
- modifier le prix
- mettre disponible/indisponible
- activer/désactiver une promotion
- supprimer un ordinateur
- rechercher dans le catalogue
- exporter/importer le catalogue JSON

Les modifications faites dans admin.html sont stockées dans le navigateur (localStorage).
Pour une vraie administration en ligne partagée par tous les visiteurs, connecter ensuite
l'interface à une base de données et un backend sécurisé.
